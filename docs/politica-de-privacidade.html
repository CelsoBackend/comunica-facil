Política de Privacidade — Comunica Fácil

Última atualização: 05/11/2026

1. Quem somos

O Comunica Fácil é um aplicativo de comunicação assistiva com botões e leitura por voz.

2. Dados tratados pelo aplicativo

O app pode tratar dados digitados pelo próprio usuário para funcionamento da aplicação, como:

  • nome de usuário;
  • e-mail;
  • textos configurados para botões e mensagens;
  • configurações e preferências da conta no próprio dispositivo.

Esses dados são usados apenas para oferecer os recursos do app.

3. Coleta e compartilhamento

  • O app não vende dados pessoais.
  • O app não compartilha dados pessoais com terceiros para publicidade.
  • O app não usa SDK de anúncios.

4. Armazenamento e retenção

  • Os dados do usuário são armazenados para manter o funcionamento da conta e dos recursos do app.
  • O usuário pode solicitar exclusão de dados entrando em contato pelo e-mail informado abaixo.

5. Segurança

Adotamos medidas técnicas razoáveis para proteger os dados tratados pelo aplicativo.

6. Crianças e adolescentes

O app não é destinado especificamente a crianças sem supervisão de responsável.

7. Contato

Para dúvidas sobre privacidade e solicitações relacionadas a dados:

  • E-mail: privacidade@comunicafacil.app

8. Publicação da política

Este documento está publicado em URL pública (HTTPS) e o mesmo link é informado na Play Console.
